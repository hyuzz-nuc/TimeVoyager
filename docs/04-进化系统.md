## 📋 功能概述

星灵进化系统，支持 4 个阶段进化，需要消耗材料和达到等级要求。

**核心特性：**
- 4 个进化阶段
- 材料消耗系统
- 未来科技风 UI
- 属性加成计算

---

## 🔄 进化阶段

| 阶段 | 名称 | 等级要求 | 材料需求 | 属性加成 |
|------|------|----------|----------|----------|
| seed→grow | 星灵之种→生长期 | Lv.20 | 进化石×10 + 晶体×500 | +20% |
| grow→mature | 生长期→成熟期 | Lv.50 | 进化石×30 + 晶体×2000 + 精华×5 | +50% |
| mature→cosmic | 成熟期→星域形态 | Lv.80 | 进化石×50 + 晶体×10000 + 精华×20 + 碎片×1 | +100% |

---

## 🎮 进化流程

```
1. 星灵等级达标
   ↓
2. 自动弹出进化弹窗（或手动点击）
   ↓
3. 显示所需材料
   ↓
4. 检查材料是否足够
   ↓
5. 点击"开始进化"
   ↓
6. 播放进化动画（2 秒）
   ↓
7. 扣除材料
   ↓
8. 阶段提升
   ↓
9. 属性重新计算
```

## 💎 材料系统

### 材料类型

| 材料 | 用途 | 获取方式 |
|------|------|----------|
| 进化石 | 所有进化阶段 | 关卡掉落/商店购买 |
| 星能晶体 | 所有进化阶段 | 专注奖励/战斗奖励 |
| 属性精华 | 高级进化 | 精英/Boss掉落 |
| 传说碎片 | 最终进化 | 隐藏 Boss 掉落 |

### 材料检查

```typescript
function canAffordEvolution(materials, cost) {
  return (
    materials.evolutionStone >= cost.evolutionStone &&
    materials.crystals >= cost.crystals &&
    materials.essence >= (cost.essence || 0) &&
    materials.legendFragment >= (cost.legendFragment || 0)
  )
}
```
