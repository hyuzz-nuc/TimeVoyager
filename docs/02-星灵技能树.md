## 1. 技能系统说明

### 1.1 技能类型

| 类型 | 英文 | 冷却 | 说明 |
|------|------|------|------|
| 基础技能 | basic | 0 | 无冷却，每回合可用 |
| 主动技能 | active | 2-6 回合 | 有冷却，强力效果 |
| 必杀技 | ultimate | 8-10 回合 | 长冷却，最强技能 |
| 被动技能 | passive | - | 自动触发，无需使用 |

### 1.2 技能解锁等级

| 等级 | 解锁内容 |
|------|----------|
| Lv.1 | 基础技能 |
| Lv.10 | 主动技能 1 |
| Lv.20 | 主动技能 2 |
| Lv.30 | 被动技能 1 |
| Lv.40 | 主动技能 3 |
| Lv.50 | 被动技能 2 |
| Lv.80 | 必杀技 |

### 1.3 技能效果类型

| 效果 | 说明 | 典型数值 |
|------|------|----------|
| `burn` | 灼烧 | 每回合损失 5% HP，持续 3 回合 |
| `poison` | 中毒 | 每回合损失 8% HP，持续 3 回合 |
| `freeze` | 冻结 | 跳过敌方回合 |
| `paralyze` | 麻痹 | 50% 概率无法行动 |
| `stun` | 眩晕 | 跳过敌方回合 |
| `bind` | 束缚 | 速度 -50% |
| `weak` | 虚弱 | 攻击/全属性降低 20-30% |
| `sleep` | 睡眠 | 跳过回合，受伤唤醒 |
| `attack_up` | 攻击提升 | 攻击力 +30-50% |
| `defense_up` | 防御提升 | 防御力 +30-50% |
| `speed_up` | 速度提升 | 速度 +30-50% |
| `heal` | 治疗 | 回复 15-50% HP |
| `shield` | 护盾 | 吸收 20-40% HP 伤害 |
