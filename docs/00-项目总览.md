## 📋 项目简介

**TimeVoyager（时光旅行者）** 是一款结合时间管理与星域探索的 PWA 应用。在这里，你的每一分钟专注都能转化为探索星域的能量，收集并培养 19 种元素星灵，见证它们从星灵之种成长为星域形态！

**核心理念：** 专注即探索，时间换世界

---

## 🎮 核心玩法

### 1. 专注计时 ⏱️

- 番茄钟工作法（25 分钟专注）
- 自定义时长设置
- 专注获得星能晶体奖励
- 白噪音播放辅助专注

### 2. 星域探索 🗺️

- 10×10 网格地图（100 个图块）
- 21 种地图图块类型
- 逐步解锁机制
- 随机奖励分布（30% 概率）

### 3. 星灵收集 ⭐

- 19 种元素星灵（7 基础 +12 星域）
- 4 个进化阶段（seed→grow→mature→cosmic）
- 等级系统（1-100 级）
- 171 个技能配置

### 4. 回合战斗 ⚔️

- 1v1 回合制战斗
- 4 星灵编队轮换
- 属性克制系统
- 15 种状态效果
- 智能敌方 AI

### 5. 星灵进化 🔄

- 未来科技风进化弹窗
- 材料消耗系统
- 阶段进化逻辑
- 属性加成计算

## 🎯 技术栈

### 前端框架

- **Vue 3.5** - 渐进式框架
- **Vite 8.0** - 构建工具
- **Pinia** - 状态管理
- **Vue Router** - 路由管理
- **Vuetify 4** - UI 组件库

### PWA 支持

- **Workbox** - 服务_worker
- **离线缓存** - 离线可用
- **推送通知** - 提醒功能

### 开发工具

- **TypeScript** - 类型安全
- **ESLint** - 代码规范
- **Git** - 版本控制

## 🚀 快速开始

### 开发环境

```bash
# 克隆项目
git clone https://github.com/hyuzz-nuc/TimeVoyager.git

# 安装依赖
cd TimeVoyager
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```
