## 📋 设计规范

### 设计风格

- **像素艺术风格** - 16-bit 像素素材
- **未来科技感** - 电光蓝 + 星尘紫配色
- **移动端优先** - 竖屏适配

### 色彩方案

**主色调：**
- 电光蓝：#00c8ff（科技/能量）
- 星尘紫：#aa44ff（神秘/进化）
- 能量青：#00ffff（速度/闪电）

**功能色：**
- 火焰红：#ff4444（攻击/生命）
- 生命绿：#44ff44（治疗/自然）
- 传说金：#ffdd44（稀有/传说）
- 暗影黑：#222222（暗系/虚空）
- 圣光白：#ffffff（光系/净化）

## 🎨 UI 组件

### 按钮样式

- 圆角：12px
- 渐变：电光蓝→能量青
- 悬停：上移 2px + 发光
- 禁用：灰色 50% 透明度

### 卡片样式

- 圆角：16px
- 背景：深空黑渐变
- 边框：1px 电光蓝
- 阴影：0 0 20px 电光蓝

### 图标规范

- 尺寸：32×32 / 24×24 / 16×16
- 风格：像素艺术
- 渲染：pixelated（保持清晰）
