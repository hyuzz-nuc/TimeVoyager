## 一、快速开始

### 1.1 环境要求

| 软件 | 最低版本 | 推荐版本 | 安装命令 |
|------|----------|----------|----------|
| Node.js | 18.x | 20.x+ | 官网下载或使用 nvm |
| npm | 9.x | 10.x+ | 随 Node.js 安装 |
| Git | 2.x | 最新 | 官网下载 |
| VSCode | - | 最新 | 推荐编辑器 |

**检查环境：**
```bash
node -v
npm -v
git --version
```

### 1.2 项目克隆与安装

```bash
# 克隆项目
git clone <repository-url>
cd TimeVoyager

# 安装依赖
npm install

# 或使用国内镜像加速
npm install --registry=https://registry.npmmirror.com
```

### 1.3 启动开发服务器

```bash
# 启动 Vite 开发服务器
npm run dev

# 访问地址：http://localhost:5173
```

### 1.4 开发模式（Electron）

```bash
# 同时启动 Vite 和 Electron
npm run electron:dev
```

## 三、核心功能开发指南

### 3.1 状态管理（timeStore.js）

**位置：** `src/stores/timeStore.js`

**核心数据结构：**
```javascript
{
  focus: {
    totalMinutes: 0,      // 累计专注分钟
    sessions: 0,          // 专注次数
    todayMinutes: 0,      // 今日专注分钟
    lastFocusDate: null   // 上次专注日期
  },
  essence: {
    total: 0,             // 累计获得精粹
    spent: 0,             // 已消耗精粹
    current: 0            // 当前可用精粹
  },
  spirit: {
    level: 1,             // 等级
    exp: 0,               // 经验值
    maxExp: 100,          // 升级所需经验
    form: 'initial',      // 形态：initial/growing/mature/cosmic
    unlockedForms: []     // 已解锁形态
  },
  explore: {
    unlockedZones: 1,     // 解锁星域数量
    currentZone: 1,       // 当前星域
    totalSteps: 0         // 总步数
  },
  achievements: {
    unlocked: []          // 已解锁成就 ID
  }
}
```

**可用 Actions：**
```javascript
// 添加专注时间（分钟）
store.addFocusTime(minutes)

// 消耗时光精粹
store.spendEssence(amount)

// 添加经验值
store.addExp(exp)

// 添加步数
store.addSteps(steps)

// 解锁成就
store.unlockAchievement(achievementId)

// 手动保存状态
store.saveState()
```

**使用示例：**
```vue
<script setup>
import { useStore } from '@/stores/timeStore'

const store = useStore()

// 访问状态
console.log(store.state.focus.todayMinutes)
console.log(store.state.essence.current)

// 修改状态
store.addFocusTime(25)
store.spendEssence(50)
</script>
```

## 四、开发工作流

### 4.1 功能开发流程

1. **创建分支**
   ```bash
   git checkout -b feature/your-feature-name
   ```

2. **开发功能**
   - 编写代码
   - 本地测试（`npm run dev`）
   - 确保无控制台错误

3. **提交代码**
   ```bash
   git add .
   git commit -m "feat: 添加 xxx 功能"
   ```

4. **推送分支**
   ```bash
   git push origin feature/your-feature-name
   ```

5. **创建 Pull Request**

### 4.2 Git 提交规范

遵循 [Conventional Commits](https://www.conventionalcommits.org/)：

| 类型 | 说明 | 示例 |
|------|------|------|
| `feat` | 新功能 | `feat: 添加番茄钟功能` |
| `fix` | 修复 bug | `fix: 修复计时器暂停问题` |
| `docs` | 文档更新 | `docs: 更新 README` |
| `style` | 代码格式 | `style: 格式化代码` |
| `refactor` | 重构 | `refactor: 优化状态管理` |
| `perf` | 性能优化 | `perf: 优化渲染性能` |
| `test` | 测试 | `test: 添加单元测试` |
| `chore` | 构建/工具 | `chore: 更新依赖版本` |

**提交示例：**
```bash
git commit -m "feat: 添加专注时长统计图表

- 新增日/周/月视图切换
- 使用 Chart.js 渲染柱状图
- 支持数据导出功能"
```

## 六、常见问题排查

### 6.1 依赖安装问题

**问题：** npm install 超时或失败

**解决：**
```bash
# 使用国内镜像
npm config set registry https://registry.npmmirror.com

# 清除缓存
npm cache clean --force

# 重新安装
rm -rf node_modules package-lock.json
npm install
```

### 6.2 端口被占用

**问题：** `Error: Port 5173 is already in use`

**解决：**
```javascript
// vite.config.js
export default defineConfig({
  server: {
    port: 5174  // 修改端口
  }
})
```

### 6.3 Electron 白屏

**问题：** Electron 窗口打开后白屏

**解决：**
1. 检查控制台错误（DevTools）
2. 确认 `base: './'` 配置正确
3. 确认构建文件在 `dist/` 目录
4. 检查路径是否正确（使用 `path.join`）

### 6.4 LocalStorage 数据丢失

**问题：** 刷新页面后数据丢失

**解决：**
1. 检查 `timeStore.js` 中的 `saveState()` 调用
2. 确认 LocalStorage 未被清除
3. 检查浏览器隐私模式（会禁用 LocalStorage）

### 6.5 PWA 无法安装

**问题：** 浏览器未显示"安装应用"提示

**解决：**
1. 确保使用 HTTPS（或 localhost）
2. 检查 `manifest.json` 配置完整
3. 确认 icons 尺寸正确（192x192, 512x512）
4. 检查 Service Worker 注册成功
