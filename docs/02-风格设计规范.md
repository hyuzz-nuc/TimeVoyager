# TimeVoyager — 风格设计规范

**版本：** 1.0  
**创建时间：** 2026-03-20  
**风格定位：** 轻科幻 + 治愈扁平 + 渐变流光

---

## 一、视觉风格核心原则

### 1.1 与 PixPet 的差异化
| 维度 | PixPet | TimeVoyager |
|------|--------|-------------|
| 风格 | 像素复古 | 现代扁平 |
| 视觉 | 8-bit 像素风 | 渐变流光 |
| 核心 IP | 像素宠物 | 时光灵体 |
| 货币 | 像素晶石 | 时光精粹 |
| 场景 | 地图探索 | 星域探索 |
| 色调 | 多彩活泼 | 蓝紫梦幻 |

### 1.2 设计关键词
- **轻科幻** - 不过度硬核，保持治愈感
- **治愈** - 柔和、舒适、无攻击性
- **扁平** - 无阴影、无立体、简洁
- **流光** - 渐变、光晕、透明感

## 六、动画规范

### 6.1 动画原则
- **轻量** - 不影响性能
- **流畅** - 60fps 优先
- **有意义** - 不为了动而动

### 6.2 标准动画
```css
/* 淡入 */
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

/* 脉冲光晕（灵体） */
@keyframes pulse {
  0%, 100% { transform: scale(1); opacity: 1; }
  50% { transform: scale(1.05); opacity: 0.8; }
}

/* 滑动进入 */
@keyframes slideIn {
  from { transform: translateY(20px); opacity: 0; }
  to { transform: translateY(0); opacity: 1; }
}
```

### 6.3 动画时长
| 类型 | 时长 |
|------|------|
| 微交互 | 150ms |
| 标准过渡 | 300ms |
| 页面切换 | 400ms |
| 循环动画 | 2-3s |

- 常用：8px, 16px, 24px, 32px, 48px

### 7.2 页面边距

## 八、响应式规范

### 8.1 断点
```css
/* 手机 */
< 600px

/* 平板 */
600px - 1024px

/* 桌面 */
> 1024px
```

### 8.2 适配原则
- 移动端优先
- 桌面端增加最大宽度限制
- 底部导航在桌面端可改为侧边栏
