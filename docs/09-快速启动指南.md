## 一、开发环境启动

### 1.1 启动开发服务器
```bash
cd E:\vibecoding\TimeVoyager
npm run dev
```

### 1.2 访问地址
- **本地：** http://localhost:5173
- **局域网：** http://<本机 IP>:5173 (需加 `--host` 参数)

### 1.3 开发服务器特性
- 热重载 (HMR)
- 源码映射
- 错误覆盖显示

## 二、Electron 开发模式

### 2.1 启动 Electron 开发
```bash
npm run electron:dev
```

### 2.2 功能
- 自动启动 Vite 开发服务器
- 自动打开 Electron 窗口
- 自动开启 DevTools

## 五、调试技巧

### 5.1 浏览器 DevTools
- 按 `F12` 或 `Ctrl+Shift+I`
- 查看 Console 错误
- 检查 Network 请求
- 使用 Vue DevTools

### 5.2 查看 LocalStorage
```javascript
// 在 Console 中运行
JSON.parse(localStorage.getItem('timevoyager_state'))
```

### 5.3 重置数据
```javascript
// 在 Console 中运行
localStorage.removeItem('timevoyager_state')
location.reload()
```

## 六、常见问题

### 6.1 端口被占用
```bash
# 修改 vite.config.js
server: {
  port: 5174
}
```

### 6.2 依赖问题
```bash
# 重新安装
rm -rf node_modules package-lock.json
npm install
```

### 6.3 Electron 启动失败
```bash
# 检查 Node 版本
node -v

# 重新安装 Electron
npm install -D electron --force
```
