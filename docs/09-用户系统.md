## 📋 功能概述

用户系统管理玩家数据、存档和偏好设置。

**核心数据：**
- 6 个功能
- localStorage 持久化
- 新手引导
- 存档管理

---

## 👤 核心功能

### 1. 用户登录/注册

- 本地账号系统
- 用户名设置
- 头像选择

### 2. 用户数据持久化

- localStorage 存储
- 自动保存
- 数据加密（可选）

### 3. 新手引导

- 5 步引导流程
- 可跳过
- 完成标记

**引导步骤：**
1. 欢迎界面
2. 星域地图引导
3. 星灵背包引导
4. 专注计时引导
5. 任务奖励引导

### 4. 用户偏好设置

- 音效开关
- 音乐开关
- 通知开关
- 语言设置（预留）

### 5. 数据统计

- 游戏时长统计
- 战斗统计
- 收集进度
- 成就完成度

### 6. 存档管理

- 自动存档
- 手动存档（预留）
- 存档导入/导出（预留）

## 📊 数据结构

```typescript
interface UserState {
  username: string           // 用户名
  hasCompletedGuide: boolean // 是否完成新手引导
  playTime: number           // 游戏时长（分钟）
  crystals: number           // 星能晶体
  coins: number              // 金币
  settings: {
    sound: boolean           // 音效
    music: boolean           // 音乐
    notifications: boolean   // 通知
  }
}
```
