## 2. 核心玩法

### 2.1 游戏循环
```
专注计时 → 获得时光精粹 → 培养星灵 → 探索星域 → 战斗获胜 → 解锁新内容
```

### 2.2 核心资源

| 资源 | 用途 | 获取方式 |
|------|------|----------|
| **时光精粹** | 基础货币，购买道具 | 专注计时（1 分钟=1 精粹） |
| **星能晶体** | 高级货币，抽卡/进化 | 成就奖励/活动/充值 |
| **进化石** | 星灵进化材料 | 商店购买/探索掉落 |
| **体力** | 探索地图消耗 | 自然恢复（5 分钟/点） |

### 2.3 星灵成长路线
```
星灵之种 (Lv.1-20) → 生长期 (Lv.21-50) → 成熟期 (Lv.51-80) → 星域形态 (Lv.81-100)
```

## 5. 战斗系统

### 5.1 战斗流程
```
1. 遭遇敌人 → 2. 确定先手（速度比较） → 3. 玩家回合 → 4. 敌方回合
       ↓                                                      ↓
   战斗胜利 ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ←
       ↓
   获得奖励（晶体/经验/道具）
```

### 5.2 战斗属性

| 属性 | 说明 | 计算公式 |
|------|------|----------|
| **HP** | 生命值 | 基础值 + 等级加成 |
| **攻击** | 物理伤害 | 基础值 + 等级加成 |
| **防御** | 减伤比例 | 基础值 + 等级加成 |
| **速度** | 决定先手 | 基础值 + 等级加成 |
| **暴击** | 暴击概率 | 基础值 + 装备加成 |
| **闪避** | 闪避概率 | 基础值 + 装备加成 |
| **命中** | 命中概率 | 基础值 + 装备加成 |

### 5.3 伤害计算
```
实际伤害 = 基础伤害 × (1 - 防御减免) × 元素克制 × 随机浮动
基础伤害 = 攻击力 × 技能倍率
防御减免 = 防御 / (防御 + 100)
随机浮动 = 0.9 ~ 1.1
```

### 5.4 元素克制

#### 基础元素克制循环
| 攻击方 | 克制 (+50%) | 被克制 (-50%) |
|--------|-------------|---------------|
| 🔥 火 | 🌿 木、🌪️ 风 | 💧 水、❄️ 冰 |
| 💧 水 | 🔥 火、⚡ 雷 | 🌿 木、🌑 暗 |
| 🌿 木 | 💧 水、🕳️ 空 | 🔥 火、🌪️ 风 |
| ⚡ 雷 | 💧 水、🌪️ 风 | 🌿 木、🕳️ 空 |
| 🌑 暗 | ✨ 光、⏰ 时 | ✨ 光、💧 水 |
| ✨ 光 | 🌑 暗 | 🌑 暗 |
| ❄️ 冰 | 🌿 木、🌪️ 风 | 🔥 火、⚡ 雷 |
| 🌪️ 风 | 🌿 木、⚡ 雷 | ❄️ 冰、🔥 火 |
| 🕳️ 空 | ⚡ 雷、⏰ 时 | 🌿 木、💫 能 |
| ⏰ 时 | 🌑 暗、💫 能 | 🕳️ 空、🌑 暗 |
| 💫 能 | 🕳️ 空、❄️ 冰 | ⏰ 时、⚡ 雷 |

#### 克制关系说明
- **火系**：燃烧万物，但遇水则灭，遇冰则消
- **水系**：熄灭火焰，但被植物吸收，被黑暗污染
- **木系**：吸收水分，但怕火焚烧，怕风折断
- **雷系**：导电于水，迅疾如风，但被植物绝缘，被虚空吞噬
- **暗系**：克制光明，侵蚀时间，但被光明净化，被水流冲刷
- **光系**：唯一与暗互克，神圣净化
- **冰系**：冻结植物，减缓风速，但怕火融化，怕雷击碎
- **风系**：助长雷势，摧折植物，但被冰冻，被火加热
- **空系**：吞噬雷电，扭曲时间，但被植物扎根，被能量填充
- **时系**：操控黑暗，转化能量，但被虚空隔绝，被黑暗侵蚀
- **能系**：填充虚空，冻结能量，但被时间消耗，被雷电干扰

#### 特殊规则
- **光暗互克**：双方对战时克制效果抵消，按无克制计算
- **时/空/能三角**：时克能、能克空、空克时，形成特殊循环
- **无克制情况**：同元素内战、部分特殊组合，伤害系数 1.0

### 11.2 素材生成流程

#### AI 生成配置
- **工具：** 阿里云 DashScope WANX-v1
- **模型：** `wanx-v1` 或 `wanx2.1-t2i-turbo`
- **尺寸：** 1024×1024 生成后裁剪至 256×256

#### 提示词模板结构
```
[主体描述] + [元素特征] + [形态阶段] + [艺术风格] + [技术规格]

示例（火焰星灵 - 星灵之种）：
"像素艺术风格，火焰元素小精灵，星灵之种形态，
小型 Q 版生物，身体由橙色和红色火焰组成，
燃烧鬃毛，热情表情，透明背景，
256x256 像素，游戏素材，清晰轮廓，非可爱向"
```

#### 生成脚本
- `scripts/gen-spirits.py` — 批量生成 19 种星灵
- `scripts/crop-spirits.py` — 裁剪 + 居中构图
- `scripts/verify-spirits.py` — 质量检查

#### 工作流程
```
1. 运行生成脚本 → 2. AI 生成原始图 → 3. 裁剪居中 → 4. 质量检查 → 5. Git 提交
```
