# TimeVoyager — 页面结构说明

**版本：** 1.0  
**创建时间：** 2026-03-20

---

## 一、页面总览

| 页面 | 路由 | 组件 | 核心功能 |
|------|------|------|----------|
| 专注 | `/` | FocusView | 番茄钟计时、精粹获取 |
| 灵体 | `/spirit` | SpiritView | 灵体展示、等级养成 |
| 探索 | `/explore` | ExploreView | 星域解锁、步数兑换 |
| 成就 | `/achievements` | AchievementsView | 成就列表、进度追踪 |

---

## 二、专注页面（FocusView）

### 2.1 页面结构
```
FocusView
├── timer-container
│   ├── timer-display
│   │   ├── time-text (计时器数字)
│   │   └── status-text (状态文字)
│   ├── controls (控制按钮组)
│   │   ├── 开始按钮
│   │   ├── 暂停按钮
│   │   ├── 继续按钮
│   │   └── 停止按钮
│   ├── duration-selector (时长选择器)
│   │   └── duration-options (4 个时长按钮)
│   └── stats-card (今日统计卡片)
│       └── stats-content
│           ├── 专注分钟数
│           └── 获得精粹数
```

### 2.2 组件状态
| 状态 | 类型 | 说明 |
|------|------|------|
| isRunning | ref(boolean) | 是否正在计时 |
| isPaused | ref(boolean) | 是否已暂停 |
| remainingSeconds | ref(number) | 剩余秒数 |
| selectedDuration | ref(number) | 选择的时长（分钟） |
| sessionEarned | computed | 本会话获得的精粹 |

### 2.3 用户交互
| 操作 | 响应 |
|------|------|
| 点击时长选项 | 更新 selectedDuration |
| 点击开始 | 启动计时器，显示暂停按钮 |
| 点击暂停 | 暂停计时，显示继续按钮 |
| 点击继续 | 恢复计时，显示暂停按钮 |
| 点击停止 | 重置计时器，无奖励 |
| 计时完成 | 发放奖励，弹出提示 |

### 2.4 视觉特点
- 超大计时器数字（96px）
- 蓝紫渐变背景
- 数字等宽字体显示
- 光晕效果突出计时器

## 三、灵体页面（SpiritView）

### 3.1 页面结构
```
SpiritView
├── spirit-container
│   ├── spirit-display (灵体展示区)
│   │   ├── spirit-avatar (灵体头像)
│   │   ├── spirit-name (名称)
│   │   └── spirit-form (形态)
│   ├── level-card (等级卡片)
│   │   ├── level-header (等级显示)
│   │   ├── exp-bar-container (经验条)
│   │   └── exp-text (经验数值)
│   ├── evolution-section (进化树)
│   │   └── evolution-timeline
│   │       └── evolution-node × 4 (4 个形态节点)
│   └── stats-grid (统计网格)
│       └── stat-card × 3 (总专注/总精粹/成就数)
```

### 3.2 计算属性
| 属性 | 说明 |
|------|------|
| formLabel | 当前形态名称 |
| expPercent | 经验条百分比 |
| spiritForm | 形态 CSS 类名 |

### 3.3 形态进化节点
| 节点 | 等级 | 图标 | 状态 |
|------|------|------|------|
| 初始形态 | Lv.1 | mdi-star-four-points-outline | 默认解锁 |
| 成长形态 | Lv.10 | mdi-star-four-points | 条件解锁 |
| 成熟形态 | Lv.30 | mdi-star-four-points-circle | 条件解锁 |
| 宇宙形态 | Lv.50 | mdi-star-four-points-box | 条件解锁 |

### 3.4 视觉特点
- 灵体头像脉冲动画
- 进化树时间线设计
- 渐变经验条
- 三列统计卡片

## 四、探索页面（ExploreView）

### 4.1 页面结构
```
ExploreView
├── explore-container
│   ├── zone-map (星域地图)
│   │   ├── map-title
│   │   └── zone-grid
│   │       └── zone-node × 6 (6 个星域节点)
│   │           ├── 星域图标
│   │           ├── 星域名称
│   │           ├── 解锁消耗
│   │           └── 解锁按钮/当前标记
│   ├── steps-card (步数卡片)
│   │   ├── steps-header
│   │   ├── steps-value (步数显示)
│   │   ├── steps-info (兑换说明)
│   │   └── add-steps-btn (添加步数按钮)
│   └── explore-tips (探索小贴士)
```

### 4.2 星域节点状态
| 状态 | CSS 类 | 视觉效果 |
|------|--------|----------|
| 已解锁 | unlocked | 边框高亮，背景色 |
| 当前所在 | current | 绿色边框，光晕 |
| 未解锁 | locked | 半透明，灰度 |

### 4.3 用户交互
| 操作 | 响应 |
|------|------|
| 点击已解锁星域 | 切换到该星域（后续） |
| 点击未解锁星域 | 显示解锁按钮 |
| 点击解锁按钮 | 扣除精粹，解锁星域 |
| 点击添加步数 | 弹出输入框 |
| 输入步数确认 | 计算奖励，更新数据 |

### 4.4 视觉特点
- 2 列网格布局
- 星域节点卡片化
- 当前星域高亮标记
- 步数大数字展示

## 六、主应用（App.vue）

### 6.1 结构
```
v-app
├── v-main
│   └── router-view (页面路由出口)
└── v-bottom-navigation (底部导航栏)
    └── v-btn × 4 (4 个导航按钮)
        ├── v-icon
        └── span (标题)
```

### 6.2 导航配置
| 按钮 | 路由 | 图标 | 标题 |
|------|------|------|------|
| 1 | / | mdi-timer-outline | 专注 |
| 2 | /spirit | mdi-star-four-points | 灵体 |
| 3 | /explore | mdi-rocket-launch | 探索 |
| 4 | /achievements | mdi-trophy | 成就 |

### 6.3 响应式行为
- 移动端：底部导航固定
- 桌面端：可增加最大宽度限制
- 安全区域：padding-bottom: env(safe-area-inset-bottom)

## 七、路由配置（router/index.js）

### 7.1 路由表
```javascript
const routes = [
  {
    path: '/',
    name: 'Focus',
    component: () => import('@/views/FocusView.vue'),
    meta: { title: '专注', icon: 'mdi-timer-outline' }
  },
  {
    path: '/spirit',
    name: 'Spirit',
    component: () => import('@/views/SpiritView.vue'),

  },
  {
    path: '/explore',
    name: 'Explore',
    component: () => import('@/views/ExploreView.vue'),
    meta: { title: '探索', icon: 'mdi-rocket-launch' }
  },
  {
    path: '/achievements',
    name: 'Achievements',
    component: () => import('@/views/AchievementsView.vue'),
    meta: { title: '成就', icon: 'mdi-trophy' }
  }

```

### 7.2 路由守卫
```javascript
router.beforeEach((to, from, next) => {
  if (to.meta.title) {
    document.title = `${to.meta.title} - TimeVoyager`
  }
  next()
})
```

## 八、状态管理（stores/timeStore.js）

### 8.1 状态结构
```javascript
state = {
  focus: {
    totalMinutes: 0,
    sessions: 0,
    todayMinutes: 0,
    lastFocusDate: null
  },
  essence: {
    total: 0,
    spent: 0,
    current: 0
  },
  spirit: {
    level: 1,
    exp: 0,
    maxExp: 100,
    form: 'initial',
    unlockedForms: ['initial']
  },
  explore: {
    unlockedZones: 1,
    currentZone: 1,
    totalSteps: 0
  },
  achievements: {
    unlocked: []
  }
}
```

### 8.2 Actions
| Action | 参数 | 功能 |
|--------|------|------|
| addFocusTime | minutes | 添加专注时间，发放奖励 |
| spendEssence | amount | 消费精粹 |
| addExp | exp | 添加经验，检查升级 |
| addSteps | steps | 添加步数，兑换精粹 |
| unlockAchievement | id | 解锁成就 |
| saveState | - | 保存到 LocalStorage |
