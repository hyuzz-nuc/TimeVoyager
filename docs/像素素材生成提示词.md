## 五、批量生成命令

### 5.1 生成像素宠物（4 个形态）

```bash

# 初始形态

python3 scripts/gen.py --model dall-e-3 --size 1024x1024 --prompt "pixel art, 8-bit style, growing light spirit, defined body shape with flowing energy trails, white background, game asset, brighter blue and gold accents, more detailed wings" --count 4
```

## 六、使用建议

### 6.1 最佳实践

1. **先生成宠物** - 核心视觉元素
2. **再生成功能图标** - 导航和交互
3. **最后生成成就图标** - 装饰性元素

### 6.2 风格统一

- 所有图标使用**白色背景**
- 保持**8-bit 像素风格**
- 颜色使用**蓝紫渐变**主色调
- 尺寸统一为**512x512**或**1024x1024**

### 6.3 后期处理

- 使用图像编辑工具统一尺寸
- 调整背景为纯白（#FFFFFF）
- 优化为 PNG 格式（透明背景可选）
- 压缩优化（TinyPNG）
