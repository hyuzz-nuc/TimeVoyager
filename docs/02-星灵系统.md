### 1.2 双属性星灵

部分星灵具有**双重元素属性**，在战斗中享受两种元素的特性：

| 星灵 | 主元素 | 副元素 | 特性说明 |
|------|--------|--------|----------|
| 星云 (nebula) | 🌿 木 | 🌑 暗 | 中毒大师，同时具有木系持续伤害和暗系减益 |
| 黑洞 (blackhole) | 🕳️ 空 | 🌑 暗 | 吞噬增益，同时具有空系规则操控和暗系吸血 |
| 专注 (focus) | 💫 能 | ⚡ 雷 | 必中必暴，同时具有能系平衡和雷系暴击 |
| 能量 (energy) | 💫 能 | ✨ 光 | 能量转换，同时具有能系转换和光系净化 |

### 1.3 元素克制关系

#### 基础克制循环
| 攻击方 | 克制 (+50%) | 被克制 (-50%) |
|--------|-------------|---------------|
| 🔥 火 | 🌿 木 | 💧 水 |
| 💧 水 | 🔥 火 | 🌿 木 |
| 🌿 木 | 💧 水 | 🔥 火 |
| ⚡ 雷 | 💧 水 | 🌿 木 |
| 🌑 暗 | ✨ 光 | ✨ 光 |
| ✨ 光 | 🌑 暗 | 🌑 暗 |
| 🕳️ 空 | ⚡ 雷 | 💫 能 |
| 💫 能 | 🕳️ 空 | ⚡ 雷 |

#### 特殊克制规则
- **光暗互克**: 双方对战时克制效果抵消，按无克制计算 (1.0×)
- **双属性计算**: 双属性星灵同时计算两种元素的克制关系，取平均值
- **同元素内战**: 无克制效果 (1.0×)

#### 克制伤害公式
```
最终伤害 = 基础伤害 × 元素克制系数 × (1 + 其他加成)

克制系数:
- 克制: 1.5×
- 被克制: 0.5×
- 无克制: 1.0×
- 双属性平均: (属性 1 系数 + 属性 2 系数) ÷ 2
```
