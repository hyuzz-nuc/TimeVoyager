**版本：** 1.0  
**创建时间：** 2026-03-20

## 一、核心功能流程

### 1.1 专注流程
```
用户进入专注页面
    ↓
选择专注时长 (15/25/45/60 分钟)
    ↓
点击「开始专注」
    ↓
计时器开始倒计时
    ↓
[计时中...]
    ↓
时间归零
    ↓
发放奖励 (时长 = 精粹数)
    ↓
灵体获得经验 (时长 × 10 EXP)
    ↓
更新 LocalStorage
    ↓
显示完成提示
    ↓
返回初始状态
```

### 1.2 专注异常流程
```
计时中...
    ↓
用户点击「暂停」
    ↓
计时器暂停
    ↓
[暂停状态]
    ↓
用户点击「继续」 → 继续计时
用户点击「停止」 → 重置计时器，无奖励
```

## 二、灵体养成流程

### 2.1 灵体升级流程
```
获得经验值
    ↓
灵体 EXP 增加
    ↓
EXP >= MAX_EXP?
    ├─ 否 → 更新显示
    └─ 是 → EXP -= MAX_EXP
            ↓
            等级 + 1
            ↓
            MAX_EXP × 1.5
            ↓
            检查形态进化
            ├─ Lv >= 50 → 宇宙形态
            ├─ Lv >= 30 → 成熟形态
            ├─ Lv >= 10 → 成长形态
            └─ 否则 → 无变化
            ↓
            更新 LocalStorage
            ↓
            显示升级动画
```

### 2.2 形态进化树
```
Lv.1  初始形态 (initial)
        ↓
Lv.10 成长形态 (growing)
        ↓
Lv.30 成熟形态 (mature)
        ↓
Lv.50 宇宙形态 (cosmic)
```

## 三、探索系统流程

### 3.1 星域解锁流程
```
用户进入探索页面
    ↓
查看星域地图
    ↓
选择已解锁星域 → 直接切换
选择未解锁星域
    ↓
检查精粹是否足够
    ├─ 不足 → 提示「精粹不足」
    └─ 足够 → 扣除精粹
            ↓
            更新解锁状态
            ↓
            切换当前星域
            ↓
            显示解锁动画
            ↓
            更新 LocalStorage
```

## 四、步数系统流程

### 4.1 步数兑换流程
```
用户添加步数
    ↓
输入步数值
    ↓
验证输入 (数字且>0)
    ↓
总步数 += 输入值
    ↓
计算精粹奖励 (步数 ÷ 1000 取整)
    ↓
精粹 += 奖励数
    ↓
更新 LocalStorage
    ↓
显示获得提示
```

## 五、成就系统流程

### 5.1 成就解锁流程
```
触发成就检查事件
    ↓
遍历所有成就
    ↓
检查成就是否已解锁
    ├─ 已解锁 → 跳过
    └─ 未解锁 → 检查条件
            ↓
            条件满足？
            ├─ 否 → 跳过
            └─ 是 → 解锁成就
                    ↓
                    添加到已解锁列表
                    ↓
                    更新 LocalStorage
                    ↓
                    显示解锁提示
```

### 5.2 成就条件检查时机
- 专注完成后
- 步数添加后
- 灵体升级后
- 星域解锁后
- 应用启动时（补发成就）

## 六、数据存储流程

### 6.1 数据读取流程
```
应用启动
    ↓
调用 loadState()
    ↓
读取 LocalStorage
    ↓
存在数据？
    ├─ 否 → 返回初始状态
    └─ 是 → JSON.parse 解析
            ↓
            合并到 initialState
            ↓
            检查每日重置
            ↓
            返回状态对象
```

### 6.2 数据写入流程
```
状态变更
    ↓
调用 saveState(state)
    ↓
JSON.stringify 序列化
    ↓
写入 LocalStorage
    ↓
完成
```

### 6.3 每日重置逻辑
```
检查 lastFocusDate
    ↓
与今日日期比较
    ├─ 相同 → 跳过
    └─ 不同 → todayMinutes = 0
            ↓
            lastFocusDate = 今日
            ↓
            保存状态
```

## 八、异常处理流程

### 8.1 精粹不足
```
尝试消费精粹
    ↓
检查 current >= amount
    ├─ 是 → 扣除并返回 true
    └─ 否 → 返回 false
            ↓
            显示提示「时光精粹不足」
```

### 8.2 存储失败
```
调用 saveState()
    ↓
try-catch 包裹
    ├─ 成功 → 完成
    └─ 失败 → 捕获异常
            ↓
            控制台记录错误
            ↓
            提示用户「保存失败」
```

### 8.3 数据损坏
```
调用 loadState()
    ↓
try-catch 包裹
    ├─ 成功 → 解析数据
    └─ 失败 → 捕获异常
            ↓
            返回初始状态
            ↓
            控制台记录错误
```

| 事件 | 触发操作 | 影响数据 |
|------|----------|----------|
| 专注完成 | addFocusTime() | focus.*, essence.*, spirit.exp |

| 获得经验 | addExp() | spirit.exp, spirit.level, spirit.form |
| 添加步数 | addSteps() | explore.totalSteps, essence.* |
| 解锁成就 | unlockAchievement() | achievements.unlocked |
| 解锁星域 | 手动更新 | explore.unlockedZones, explore.currentZone |
