## 一、部署到 GitHub Pages（Web 版）

### 1.1 创建 GitHub 仓库

1. 访问 https://github.com/new
2. 仓库名：`time-voyager`
3. 可见性：Public
4. 点击 "Create repository"

### 1.2 关联远程仓库

```bash
cd E:\vibecoding\TimeVoyager

# 添加远程仓库（替换为你的 GitHub 用户名）
git remote add origin https://github.com/YOUR_USERNAME/time-voyager.git

# 验证
git remote -v
```

### 1.3 安装 gh-pages

```bash
npm install -D gh-pages
```

### 1.4 添加部署脚本

在 `package.json` 的 `scripts` 中添加：

```json
{
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview",
    "deploy": "npm run build && npx gh-pages -d dist"
  }
}
```

### 1.5 部署

```bash
# 构建并部署
npm run deploy

# 等待部署完成（约 1-2 分钟）
```

### 1.6 配置 GitHub Pages

1. 进入仓库 Settings → Pages
2. Source 选择 `gh-pages` 分支
3. 等待部署完成
4. 访问：`https://YOUR_USERNAME.github.io/time-voyager/`

### 1.7 自定义域名（可选）

1. 在 `public/` 目录创建 `CNAME` 文件
2. 内容：`yourdomain.com`
3. 在域名服务商处配置 CNAME 记录

## 七、CI/CD 自动化（GitHub Actions）

### 7.1 创建 workflow 文件

`.github/workflows/deploy.yml`:

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [ main ]

jobs:
  deploy:
    runs-on: ubuntu-latest
    
    steps:
      - uses: actions/checkout@v3
      
      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '20'
      
      - name: Install dependencies
        run: npm ci
      
      - name: Build
        run: npm run build
      
      - name: Deploy
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./dist
```

### 7.2 推送触发

```bash
git push
```

GitHub Actions 会自动构建和部署。

## 八、性能优化建议

### 8.1 构建优化

```javascript
// vite.config.js
export default defineConfig({
  build: {
    rollupOptions: {
      output: {
        manualChunks: {
          vendor: ['vue', 'vue-router'],
          vuetify: ['vuetify']
        }
      }
    }
  }
})
```

### 8.2 图片优化

- 使用 WebP 格式
- 压缩图片（TinyPNG）
- 使用 CDN

### 8.3 CDN 加速

```javascript
// vite.config.js
export default defineConfig({
  build: {
    rollupOptions: {
      external: ['vue', 'vue-router'],
      output: {
        globals: {
          vue: 'Vue',
          'vue-router': 'VueRouter'
        }
      }
    }
  }
})
```

在 `index.html` 中添加 CDN：

```html
<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script src="https://unpkg.com/vue-router@4/dist/vue-router.global.js"></script>
```

## 十、常见问题

### Q1: GitHub Pages 刷新 404

**解决：** 添加 `public/_redirects` 文件

```
/*    /index.html   200
```

### Q2: Vercel 构建失败

**解决：** 检查 Node.js 版本，在 Vercel 设置中指定

### Q3: PWA 无法安装

**解决：**
- 确保使用 HTTPS
- 检查 manifest.json 配置
- 确认 Service Worker 注册成功

### Q4: Electron 打包后白屏

**解决：**
- 检查 `base: './'` 配置
- 确认路径使用 `path.join`
- 查看控制台错误
