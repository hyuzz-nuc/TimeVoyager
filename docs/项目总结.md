## 一、项目概述

### 1.1 项目定位

一款**专注计时 + 放置类游戏**应用，将番茄工作法与游戏化元素结合，通过专注时间培养"时光灵体"，探索神秘星域。

### 1.2 目标用户

- 需要提升专注力的学生/职场人士
- 喜欢游戏化体验的用户
- 追求精致 UI 设计的年轻群体

### 1.3 核心价值

- **专注变现** - 将专注时间转化为游戏内货币
- **养成乐趣** - 见证灵体从弱小到强大的进化过程
- **探索驱动** - 解锁新星域，保持长期动力
- **成就激励** - 12 个成就挑战，记录成长轨迹

## 六、部署方案

### 6.1 Web 版

**GitHub Pages:**
```bash
npm run build
npx gh-pages -d dist
```

**Vercel:**
```bash
vercel --prod
```

**Netlify:**
```bash
netlify deploy --prod --dir=dist
```

### 6.2 桌面版

**Windows:**
- 安装包：`release/TimeVoyager Setup 1.0.0.exe`
- 静默安装：`TimeVoyager Setup 1.0.0.exe /S`

**macOS:**
- 安装包：`release/TimeVoyager-1.0.0.dmg`
- 拖拽安装到 Applications

**Linux:**
- 免安装包：`release/TimeVoyager-1.0.0.AppImage`
- 执行权限：`chmod +x *.AppImage`

## 八、经验总结

### 8.1 成功经验

1. **游戏化设计** - 将枯燥的专注变得有趣
2. **快速迭代** - 2 天完成 MVP 版本
3. **文档先行** - 边开发边写文档
4. **技术选型** - Vue 3 + Vite 开发体验极佳
5. **跨平台** - 一次开发，多端部署

### 8.2 踩坑记录

1. **npm 安装超时** - 使用国内镜像解决
2. **vite-plugin-pwa 版本冲突** - 使用 --legacy-peer-deps
3. **Electron 路径问题** - 使用 path.join 处理跨平台路径
4. **LocalStorage 键名冲突** - 使用唯一键名 `timevoyager_state`

### 8.3 改进建议

1. **早期规划数据结构** - 避免后期重构
2. **单元测试** - 核心功能应尽早添加测试
3. **错误处理** - 完善全局错误捕获
4. **性能监控** - 添加性能追踪
